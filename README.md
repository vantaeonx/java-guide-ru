# Java с нуля — учебное пособие на русском

**20 глав, 180 самостоятельных упражнений, 6 мини-проектов и PDF на 258 страниц.**
От первых классов и примитивов до ООП, коллекций, generics и файлового приложения.
Основной синтаксис и стандартные API совместимы с **Java 17**. Работать можно на JDK 25.
Готовых решений упражнений и проектов в репозитории нет.

## Первый запуск в IntelliJ IDEA

1. Скачай архив проекта (на GitHub: **Code → Download ZIP**), распакуй в доступное место. Имя внешней папки не важно.
2. В IDEA выбери **File → Open** и папку, в которой находятся `pom.xml` и этот README.
   Если предлагается импорт Maven, согласись. Первое скачивание плагина Maven требует сети.
3. Открой **File → Project Structure → Project**. Выбери установленный **JDK 25**
   как Project SDK, а **Language level — 17**, без preview. При необходимости укажи
   путь JDK через Add SDK. JDK, которым запущена сама IDEA, не обязательно является SDK проекта.
4. Если проект открылся без Maven, пометь `src/main/java` через
   **Mark Directory as → Sources Root**. Не помечай корнем `ch01`.
   В этой папке лежат все независимые упражнения.
5. Открой `src/main/java/ru/vantaeonx/javaguide/ch01/Ex001.java`.
   Прочитай условие, впиши автора, допиши только свою рабочую область, сохрани.
6. Нажми зелёный треугольник возле `main` → **Run 'Ex001.main()'**.
   Вывод и ввод находятся в панели Run, а не в редакторе исходника.

Пустой вывод у ещё не решённой заготовки нормален. Методы с
`UnsupportedOperationException("TODO")` нужно реализовать **до вызова**.
Примеры из теории лежат в `examples/Example01.java`–`Example20.java`; проще запускать их
терминальной командой ниже. Они показывают другую ситуацию и не являются ответами задач.

Если IDEA пытается собирать весь модуль, а ты временно сломал другое упражнение,
запусти нужное через `tools/run.sh`: он компилирует только выбранный файл.
Не удаляй package и не переименовывай классы в Main.

## Ubuntu 26.04: проверить инструменты

Открой терминал и выполни по отдельности:

```bash
java -version
javac -version
```

Нужны обе команды. Если установлен JDK 25 и обе показывают 25, переустановка не нужна.
Если `javac` отсутствует, установи JDK из доступных пакетов Ubuntu:

```bash
sudo apt update
sudo apt install openjdk-25-jdk
```

Если в используемых репозиториях такого пакета нет, используй имеющийся JDK 17+ или
официальный дистрибутив JDK. Для JDK 17 пакет обычно называется `openjdk-17-jdk`;
сначала проверь `apt policy openjdk-17-jdk`. Курс не требует удалить JDK 25.
При нескольких JDK можно проверить `update-alternatives --display java` и
`update-alternatives --display javac`; версия терминала и SDK в IDEA настраиваются отдельно.

Команды ниже запускай из **корня java-guide-ru**, где лежит `pom.xml`:

```bash
bash tools/run.sh Ex001
bash tools/run.sh Ex028
bash tools/run.sh Project01
bash tools/run.sh Example04
```

Последняя команда ждёт две строки: город, затем число. Упражнения на ввод содержат
свой протокол и пример в комментариях. Цифры после точки вводи с точкой там, где это
прямо указано. Аргументы main передаются после имени:

```bash
bash tools/run.sh Ex180 sum 4 -2 7
```

До решения Ex180 ничего не выведет: это команда проверки **твоей будущей реализации**.
`Ctrl+C` останавливает ошибочно написанный бесконечный цикл.

Без скриптов одно упражнение можно собрать так:

```bash
mkdir -p build/classes
javac --release 17 -encoding UTF-8 -d build/classes src/main/java/ru/vantaeonx/javaguide/ch01/Ex001.java
java -cp build/classes ru.vantaeonx.javaguide.ch01.Ex001
```

`--release 17` проверяет синтаксис, стандартные API и целевой байткод. Одна настройка
Language level в редакторе этого полностью не заменяет. Для всех исходников сразу:

```bash
bash tools/build.sh
```

Maven необязателен для упражнений. Если используешь его: `mvn compile`; настройки
компилятора уже есть в `pom.xml`. В IDEA Maven может использовать встроенный Maven.

## Как решать без готовых ответов

Прочитай главу, запусти отдельный пример, измени в нём одно значение и объясни результат.
В задаче сначала запиши прогноз или план. Затем напиши код и проверь все случаи из условия,
добавив хотя бы один свой граничный случай. Запиши причину ошибки, а не только исправленную строку.
Вернись к заданию через 1, 7 и 21 день и попробуй объяснить решение без просмотра.

В исправительных упражнениях есть метка **НАМЕРЕННАЯ ОШИБКА**. Опасные или
некомпилируемые фрагменты находятся в блоке комментария, чтобы остальные задания
можно было открывать и собирать. Перенеси фрагмент в рабочую область, соблюдая контекст:
классы и методы — в тело внешнего класса, инструкции — в main. Имя публичного класса
оставь ExNNN. Вопросы только на объяснение не требуют запуска опасного кода.

Проверочные результаты — спецификация поведения, а не программные решения. В задачах
на прогноз точные ответы не раскрываются: сначала подумай, затем используй запуск.

**Ученику не нужно запускать generate.py.** Это редакторский инструмент:
`python3 tools/generate.py --write` перезаписывает стартовые файлы и уничтожит внесённые
туда решения. Для проверки редакторской синхронизации используется команда без `--write`.
В своей учебной копии она закономерно сообщает отличия после решения задач.

Редакторская проверка исходной версии (Python 3, JDK 17+):

```bash
python3 tools/verify.py
```

Проверяются 180+6 отдельных компиляций, запуск неизменённых каркасов, 20 примеров
с точным выводом, нумерация, уровни, форматы, ссылки и синхронизация. Это не автопроверка
твоих решений. При изменённых упражнениях пользуйся `run.sh` и своими проверками.

Для пересборки PDF нужны Python-пакеты `reportlab` и `pypdf`, а для визуальной проверки —
Poppler. Установка в отдельное окружение:

```bash
python3 -m venv .venv
.venv/bin/pip install -r tools/requirements-pdf.txt
.venv/bin/python tools/build_pdf.py
.venv/bin/python tools/check_pdf.py
```

Шрифты DejaVu берутся из стандартного пути Ubuntu. При их отсутствии установи
`fonts-dejavu-core`; в PDF шрифты встраиваются, читателю установка не нужна.
Подробнее: [редакторская проверка](docs/QUALITY.md), [источники](docs/SOURCES.md).

## Если не запускается

| Симптом | Что проверить |
|---|---|
| java есть, javac нет | Нужен JDK, а не только runtime |
| invalid flag: --release | Используется слишком старый javac |
| unsupported class file version | Запускается более старый Java, чем целевой байткод |
| main не найден | Регистр main, сигнатура и выбранная конфигурация Run |
| class not found | Корень classpath и полное имя с пакетом |
| Ничего не выведено | Это ещё пустая заготовка или не та точка входа |
| TODO / UnsupportedOperationException | Метод ещё не реализован, но уже вызван |
| Ввод «пропустился» | Смешаны nextInt/nextLine без учёта остатка строки |
| Кириллица испорчена | UTF-8 в файле, компиляции, терминале и файловой операции |
| Другой файл мешает сборке IDEA | Сохрани исправление или используй run.sh для одной задачи |
| Относительный файл не найден | Проверь рабочую директорию, не путь исходника |

## Происхождение, границы и публикация решений

Педагогическая отправная точка — [python-guide-ru](https://github.com/vantaeonx/python-guide-ru).
Сохранены уровни, независимые заготовки, чтение и исправление кода. Тексты и сценарии
написаны для Java; Python-задачи не переносились заменой синтаксиса. В оригинале указана
благодарность Nicolas Hinckxt за структуру PHP-сборника, на котором вырос Python-гайд.
[Подробный анализ](docs/ORIGINAL_REVIEW.md).

Это фундамент языка и небольших консольных приложений. Для Minecraft далее понадобятся
документация конкретной версии и загрузчика, их требования к JDK и отдельная практика API.
Сеть, базы данных, многопоточность и большие фреймворки не заявлены как освоенные этим курсом.

В публичные Issues/PR присылай опечатки, неоднозначные условия и воспроизводимые дефекты
материалов. Готовые решения упражнений в публичную ветку не принимаются. Храни свои решения
в локальной или приватной учебной копии. Лицензия материалов и кода: [MIT](LICENSE).
