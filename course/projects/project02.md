# Мини-проект 02. Панель телеметрии

После главы 09. Цикл команд, массив измерений, методы и числовая статистика.

## Договор приложения

Храни до 20 целых измерений -1000..1000 в массиве и отдельном size. Читай команды построчно: add N, stats, clear, exit. В add число корректно записано, но может быть вне диапазона. При успехе add -> ADDED, при заполнении -> FULL, неверном диапазоне -> INVALID. Stats на пустом наборе -> EMPTY, иначе одна строка COUNT:n MIN:a MAX:b AVG:v (с 2 знаками и Locale.ROOT). Clear -> CLEARED. Неизвестная команда -> UNKNOWN. Exit -> BYE; EOF завершает без BYE. Выдели вычисления в методы; среднее считай только по первым size ячейкам. Коллекции не используй.

## Исходные данные

```java
int capacity = 20;
int[] readings = new int[capacity];
int size = 0;
```

## Демонстрационный ввод

```input
add 10
add -2
stats
clear
stats
exit
```

## Этапы

1. Сначала реализуй add и отдельный счётчик size.
2. Напиши методы min, max, sum для занятой части массива.
3. Добавь цикл команд и полный договор пустоты.
4. Прогони сценарии заполнения, очистки и повторного добавления.

## Критерии готовности

- Пример -> ADDED,ADDED,COUNT:2 MIN:-2 MAX:10 AVG:4.00,CLEARED,EMPTY,BYE.
- После 20 успешных add 21-я команда даёт FULL без изменения данных.
- Неиспользованные нулевые ячейки не влияют на статистику.
- После clear новый add начинает заполнение с позиции 0.
