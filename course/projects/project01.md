# Мини-проект 01. Консольный пункт выдачи

После главы 05. Одна операция оформления отправления: ввод, арифметика, проверки и ветвления.

## Договор приложения

Прочитай четыре строки: получатель (непустой, без краевых пробелов), масса в граммах (целое 1..30000), зона (local или remote), признак fragile (yes или no). На этом этапе числовая строка гарантированно преобразуется в int. Остальные нарушения дают INVALID, никакая цена тогда не печатается. Цена: local 300 центов, remote 700; дополнительно 100 за каждый начатый килограмм и 250 за fragile=yes. Выведи получателя, число килограммов и итоговые центы на трёх строках. Нулевой и отрицательный вес недопустимы. Повтор команд пока не нужен.

## Исходные данные

```java
String sampleRecipient = "Лея";
int sampleGrams = 1201;
String sampleZone = "local";
String sampleFragile = "yes";
```

## Демонстрационный ввод

```input
Лея
1201
local
yes
```

## Этапы

1. Составь таблицу допустимых полей и цены каждой зоны.
2. Реализуй чтение по строкам без потери имени с пробелами.
3. До расчёта проверь все поля; раздели ошибку и корректный результат.
4. Добавь расчёт начатых килограммов и проверь точки 1000/1001.

## Критерии готовности

- Исходный пример -> Лея, 2, 750.
- Рин/1000/remote/no -> Рин,1,800; 1001 -> 2,900.
- Пустое имя, масса 0 или 30001, зона moon, fragile=maybe -> только INVALID.
- В README проекта опиши точный порядок строк и единицу цены.
