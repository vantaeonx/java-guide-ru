Перепиши фрагмент: Notifier должен получать Channel в конструкторе. Реализуй MemoryChannel, сохраняющий последнее сообщение в String и число вызовов в int. При notify("ok") последнее сообщение ok, вызов один.

```java
interface Channel { void send(String text); }
static class ConsoleChannel implements Channel {
    public void send(String text) { System.out.println(text); }
}
static class Notifier {
    void notify(String text) { new ConsoleChannel().send(text); }
}
```

### Проверь себя

- Проверка не печатает в консоль из канала.
- Notifier не создаёт ConsoleChannel внутри метода.
