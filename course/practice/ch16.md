Уровень 1 · Найти ошибку · [Ex138.java](../../src/main/java/ru/vantaeonx/javaguide/ch16/Ex138.java)

**Перед началом.** Равные ключи обязаны иметь равные hashCode.

Найди нарушение договора класса Key и исправь equals/hashCode согласованно. Сравнивай id; null-id запрещён конструктором по договору. Проверь поиск через новый равный Key.

### Намеренная ошибка / фрагмент для анализа

Фрагмент оставлен в комментарии стартового Java-файла. При исправлении перенеси необходимые части в рабочую область. Если условие просит только объяснить, запускать опасный вариант не нужно.

```java
static class Key {
    private final String id;
    Key(String id) { this.id = id; }
    @Override public boolean equals(Object other) {
        return other instanceof Key && id.equals(((Key) other).id);
    }
    // hashCode отсутствует намеренно
}
```

### Проверь себя

- Два Key("A") равны и имеют равный хеш.
- После put первым ключом get вторым находит значение; коллизия не считается равенством.
