**Перед началом.** Внешнее имя файла и имя public-класса должны согласовываться.

В комментарии дан отдельный файл Probe.java. Найди все причины, по которым он не компилируется. Исправленный вариант запиши в рабочей области без второго public-класса; результат main должен быть «Готово».

### Намеренная ошибка / фрагмент для анализа

Фрагмент оставлен в комментарии стартового Java-файла. При исправлении перенеси необходимые части в рабочую область. Если условие просит только объяснить, запускать опасный вариант не нужно.

```java
// Воображаемый файл Probe.java
public class probe {
    public static void Main(String[] args) {
        system.out.println("Готово")
    }
}
```

### Проверь себя

- Укажи нарушения имени и регистра, а также синтаксиса.
- Исправленная рабочая область текущего файла компилируется и печатает «Готово».
