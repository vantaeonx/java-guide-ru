# 06. Циклы: повторение с доказуемой остановкой

## Повторяется тело, а не намерение

Цикл нужен, когда одно действие применяется к последовательности данных или выполняется до наступления события. В while сначала проверяется условие, затем тело. Поэтому тело может не выполниться ни разу. В do/while тело выполняется до первой проверки, хотя бы один раз. For объединяет инициализацию, условие и изменение счётчика в одном заголовке.

Для `for (int i = 0; i < n; i++)` порядок таков: создать i, проверить i < n, выполнить тело, увеличить i, снова проверить. После закрытия цикла локальное i из заголовка недоступно. Если n равно нулю, повторений нет. Условие `i <= n` добавляет ещё одно повторение и часто ломает доступ к массиву.

## Состояние и инвариант

У цикла есть состояние: счётчик, накопленная сумма, число найденных элементов. Инвариант - утверждение, которое сохраняется при переходе к следующей итерации. Например, перед обработкой элемента с индексом i сумма уже содержит первые i элементов. Это объясняет начальное значение 0 и границу i < length.

Для остановки нужен прогресс: величина, которая приближает состояние к ложному условию. В обратном отсчёте уменьшается счётчик. В чтении до команды выхода источник должен когда-нибудь дать эту команду или закончиться. Если обновление забыто, изменение условия наугад не решает причину.

```java
public class Example06 {
    public static void main(String[] args) {
        int total = 0;
        for (int day = 1; day <= 4; day++) {
            total += day * 3;
        }
        System.out.println(total);
        int remaining = 3;
        while (remaining > 0) {
            System.out.print(remaining + " ");
            remaining--;
        }
        System.out.println("готово");
    }
}
```

```output
30
3 2 1 готово
```

В первом цикле до дня k сумма содержит вклад предыдущих дней. Во втором remaining не только печатается, но и уменьшается. Проследи вручную состояние перед проверкой, внутри тела и после изменения: это три разные точки времени.

## Break, continue и вложенность

Break завершает ближайший цикл. Continue переходит к следующей итерации: в for выполняется шаг из заголовка, в while выполнение возвращается прямо к условию. Поэтому continue перед обновлением счётчика while способен создать бесконечный цикл.

Во вложенных циклах внутренний цикл запускается заново для каждого шага внешнего. Два прохода по n элементов не равны n*n: последовательные проходы дают около 2n действий, вложенные - около n*n. Эта разница становится заметной на больших данных. Сначала считай, сколько раз выполняется тело, затем обсуждай скорость.

## Алгоритмы накопления

Для суммы начальное значение обычно 0, для произведения 1, для счётчика найденных 0. Для максимума неизвестных данных нельзя всегда брать 0: весь набор может быть отрицательным. Используй первый допустимый элемент или отдельно учитывай отсутствие данных. Пока массивы не изучены, это можно увидеть на последовательности значений из ввода.

Условие завершения не всегда является данными для обработки. Если договор задаёт 0 как сигнал остановки, этот 0 обычно не включают в статистику. Если ноль может быть полезным значением, выбери другой протокол: количество элементов заранее или отдельную команду.

## Ошибки и проверка понимания

Частые ошибки: сброс суммы внутри тела; изменение не того счётчика; пропуск обновления на ветке continue; неверная граница; включение сигнала остановки в результат. Для проверки возьми минимальный вход: ноль повторений, одно повторение, затем два. Большой пример плохо показывает момент первой ошибки.

Перед практикой составь таблицу `итерация / условие / состояние до / состояние после`. Назови инвариант и причину остановки. Если не можешь их сформулировать, алгоритм ещё не ясен независимо от того, запускается ли он на одном входе.
