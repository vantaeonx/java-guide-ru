# 18. Файлы, пути и устойчивый текстовый формат

## Путь не равен содержимому файла

Path представляет путь в файловой системе. Само создание Path не открывает файл и не доказывает его существование. Относительный путь вычисляется от рабочей директории процесса, которая в IDEA может отличаться от папки исходника. Для диагностики полезно вывести path.toAbsolutePath, но не зашивать личный абсолютный путь в проект.

Files содержит операции чтения, записи и управления. В курсе для текста явно указывается StandardCharsets.UTF_8: русские данные не должны зависеть от системной кодировки. Расширение `.txt` само по себе не задаёт кодировку или формат полей.

```java
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;

public class Example18 {
    public static void main(String[] args) throws IOException {
        Path directory = Files.createTempDirectory("java-guide-");
        Path file = directory.resolve("routes.txt");
        try {
            Files.write(file, List.of("порт;12", "парк;5"),
                    StandardCharsets.UTF_8);
            List<String> lines = Files.readAllLines(file,
                    StandardCharsets.UTF_8);
            System.out.println(lines.size());
            System.out.println(lines.get(0));
        } finally {
            Files.deleteIfExists(file);
            Files.deleteIfExists(directory);
        }
    }
}
```

```output
2
порт;12
```

Пример использует временную папку и удаляет её. Throws передаёт IOException вызывающей среде; это демонстрация операции, а не конечный пользовательский интерфейс. В мини-проекте ошибки должны получить понятное сообщение на уровне команды.

## Чтение целиком и потоковое чтение

ReadString и readAllLines удобны для маленьких файлов. Они загружают содержимое в память. Для большого журнала нужен BufferedReader или поток строк. Поток от Files.lines владеет открытым ресурсом: используй try-with-resources и не возвращай его из метода, который уже закрыл ресурс.

Проверка Files.exists перед чтением не гарантирует успех: файл может исчезнуть между действиями. Лучше попытаться выполнить нужную операцию и обработать IOException. Проверка существования иногда полезна для пользовательского сценария, но не заменяет обработку отказа.

## Формат - часть договора

Пусть запись имеет вид `name;count`. Нужно определить: разрешён ли `;` внутри имени, допустимы ли пустые поля, что означает пробел, какой диапазон count, как представлены переводы строки. В учебных задачах разделитель внутри имени запрещён. Это простой формат с ограничением, а не полноценный CSV.

При разборе используй split с сохранением пустого последнего поля и проверяй количество полей до индексации. Номер строки и причина отказа важнее общего «не удалось прочитать». Выбери политику: прекратить загрузку целиком или пропустить ошибочные строки с отчётом. Нельзя молча потерять записи.

## Запись и сохранность данных

Обычная запись может создать файл или обрезать существующий. Режим добавления задаётся явно через StandardOpenOption.APPEND и CREATE, если это требуется. Родительские каталоги не всегда создаются автоматически; Files.createDirectories решает отдельную задачу.

Для сохранения важных данных сначала подготовь полное новое содержимое, запиши во временный файл в том же каталоге, затем замени целевой через move. AtomicMove может быть не поддержан файловой системой; политика запасного варианта должна быть явной. Даже такая схема не равна универсальной транзакционной базе данных и не гарантирует защиту от всех сбоев питания без дополнительных мер.

В заданиях запись выполняется только в `build/sandbox` или во временную папку. Не проверяй удаление и перезапись на личных файлах. Пути из пользовательского ввода требуют отдельного ограничения, если приложение должно оставаться внутри выделенного каталога.

## Ошибки и самопроверка

Проверь пустой файл, отсутствие, русскую строку, повреждённую запись и последний перевод строки. Отделяй ошибку файловой операции от ошибки формата: IOException и NumberFormatException говорят о разных причинах.

Перед практикой объясни, откуда считается относительный путь. Назови момент открытия ресурса. Напиши словами договор строки данных и политику отказа до того, как начнёшь разбирать её кодом.
