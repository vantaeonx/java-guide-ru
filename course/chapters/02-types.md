# 02. Переменные, типы и значения

## Зачем тип известен заранее

Переменная - именованное место для значения определённого типа. Объявление `int count = 4` одновременно задаёт тип, имя и начальное значение. Присваивание меняет значение, а не смысл имени и не объявленный тип. В отличие от привычных сценариев PHP, строка с цифрами не превращается автоматически в целое при присваивании int.

Статическая проверка позволяет обнаружить несовместимость до запуска. Она не знает всего о реальности: int может хранить отрицательный возраст, если программа это разрешила. Тип ограничивает представление, а предметный смысл проверяет твой код.

## Восемь примитивов

`byte`, `short`, `int`, `long` хранят целые числа со знаком, соответственно 8, 16, 32 и 64 бита. Для обычного счётчика подходит int, для больших сумм - long. `float` и `double` хранят приближённые двоичные значения; double обычно удобнее для учебных измерений. `char` хранит одну 16-битную кодовую единицу UTF-16, которая не всегда является целым символом для человека. `boolean` принимает только true или false. У boolean нет арифметического значения 0 или 1.

Литерал `7` имеет тип int, `7L` - long, `7.0` - double, `7.0f` - float. Суффикс L нужен до вычисления, а не после переполнения. Символьный литерал пишется в одинарных кавычках, строковый - в двойных: `'Q'` и `"Q"` имеют разные типы.

## Преобразование и потеря информации

Расширение int в long сохраняет целое значение. Не всякое расширение сохраняет точность: большой long при переводе в double может округлиться. Сужение double в int отбрасывает дробную часть по направлению к нулю; это не округление до ближайшего. Явное приведение `(int)` говорит компилятору, что риск принят, но не делает результат математически точным.

В выражении байты и короткие целые обычно продвигаются до int. Поэтому сумма двух byte не обязана помещаться в byte даже при допустимых исходных значениях. Не ставь приведение только ради исчезновения ошибки: сначала оцени диапазон результата.

```java
public class Example02 {
    public static void main(String[] args) {
        int pages = 125;
        long totalPages = pages;
        double measure = -3.8;
        int truncated = (int) measure;
        final int DAYS = 7;
        System.out.println(totalPages);
        System.out.println(truncated);
        System.out.println(DAYS);
    }
}
```

```output
125
-3
7
```

Исходная measure не меняется при приведении: преобразованное значение записано в другую переменную. `final` запрещает повторное присваивание этой переменной. Позже мы увидим: final-ссылка не делает сам объект неизменяемым.

## Инициализация, область видимости, ссылки

Локальную переменную нужно инициализировать до чтения. Компилятор требует, чтобы значение существовало на каждом возможном пути к использованию. Поля объектов получают значения по умолчанию, но это другой механизм, который не нужно переносить на локальные переменные.

Область видимости локального имени ограничена блоком объявления. Переменная внутри if не становится доступной после закрывающей скобки. Выбирай минимальную достаточную область: это уменьшает число мест, где значение можно случайно изменить.

String и массивы не примитивы. Переменная ссылочного типа хранит ссылочное значение, позволяющее обратиться к объекту, либо null. Нельзя использовать null как ноль или пустую строку. Присваивание ссылки не копирует объект. Эта разница станет центральной при изучении массивов и классов.

В Java 17 `var` разрешает вывод типа некоторых локальных переменных из инициализатора. Это не динамическая типизация: `var n = 2` всё равно создаёт int. В первых заданиях используй явные типы, чтобы выбор представления был осознанным.

## Ошибки и проверка понимания

Не считай double универсальной заменой всех типов: он плохо подходит для точного учёта денежных единиц. Для учебных денежных задач используй целое число центов; BigDecimal можно изучить позднее. Не используй char как гарантированный «один эмодзи».

Перед практикой назови тип литералов `12`, `12L`, `12.0`, `'1'`, `"1"`. Объясни, какие сведения теряются при сужении и почему локальная переменная без значения не равна нулю.
