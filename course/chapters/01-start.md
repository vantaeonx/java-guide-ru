# 01. Как Java-программа становится работающей программой

## Цель и исходная модель

Программа - точное описание действий над данными. Компьютер не догадывается о намерении автора: неверное выражение может быть допустимой программой. Поэтому нужно различать три вопроса: правильно ли записан код, можно ли выполнить его на данных и соответствует ли результат условию.

Java-код хранится в текстовом файле `.java`. Компилятор `javac` проверяет грамматику, имена, типы и доступ, затем создаёт `.class` с байткодом. JVM загружает классы и выполняет байткод; реализация JVM может переводить часто исполняемый код в машинные инструкции. JDK содержит инструменты разработки и среду выполнения. IntelliJ IDEA помогает редактировать и запускать код, но выбранный в проекте JDK остаётся отдельной настройкой.

Путь выполнения: исходник -> проверка компилятором -> байткод -> загрузка JVM -> вызов main. Ошибка компиляции возникает до запуска. Ошибка выполнения появляется после старта. Логическая ошибка может не вызвать ни одного сообщения системы.

## Почему здесь нужен класс

В этом курсе используется обычная структура Java 17. Публичный верхнеуровневый класс `Example01` хранится в `Example01.java`. Тело класса заключено в фигурные скобки. Внутри находится метод `main`: точка входа, которую запускает JVM. В более новых Java есть другие формы запуска, но сначала полезно освоить структуру, которая встречается в библиотеках и обычных проектах.

`public` разрешает доступ к методу извне, `static` позволяет вызвать его без создания объекта, `void` означает отсутствие возвращаемого значения. `String[] args` - массив аргументов командной строки. Пока это готовый контракт запуска; главы о методах и объектах объяснят каждую часть глубже. Аргументы не равны данным, которые пользователь вводит через Scanner после старта.

Инструкция обычно заканчивается `;`. Блок объединяет инструкции в `{ ... }`. Отступ делает вложенность видимой человеку, но блок задают скобки. Имена чувствительны к регистру: `main`, `Main` и `MAIN` различаются. Комментарий `//` продолжается до конца строки, `/* ... */` занимает блок. Комментарии не выполняются.

## Отдельный учебный пример

```java
public class Example01 {
    public static void main(String[] args) {
        System.out.print("Маршрут: ");
        System.out.println("север");
        System.out.println("Длина: " + 8);
    }
}
```

```output
Маршрут: север
Длина: 8
```

`print` не переводит строку, `println` переводит. Выражение после `+` здесь формирует строку. Кавычки обозначают границы строкового литерала и не выводятся. Код выполняется сверху вниз внутри main. Запусти пример отдельно, затем замени один println на print и объясни изменение разметки вывода.

## Пакет, путь и имя запуска

Пакет - пространство имён, а не просто декоративная папка. Упражнение `Ex001` находится в пакете `ru.vantaeonx.javaguide.ch01`; первая строка объявляет этот пакет. Путь от корня исходников повторяет его части: `ru/vantaeonx/javaguide/ch01/Ex001.java`. Полное имя класса - пакет и имя через точку.

При ручной компиляции `-d build/classes` задаёт корень байткода. При запуске `-cp build/classes` задаёт место поиска классов, после него пишется полное имя класса без `.java` и `.class`. Запуск случайного файла из другой папки - частая причина `ClassNotFoundException`. В IDEA корнем исходников является `src/main/java`, а не папка `ch01`.

## Ошибки и способ диагностики

Если компилятор сообщает о пропущенной скобке в конце файла, причина может быть выше. Начинай с первого сообщения, сверяй пары скобок и кавычек. Если класс называется не как файл, исправь согласованно имя файла и объявления. Если программа ничего не печатает, проверь наличие вызова вывода и то, что запущен нужный main: пустая заготовка в курсе законно ничего не выводит.

Не исправляй все сообщения одновременно наугад. Сделай одно изменение, сохрани, собери снова. Так ты проверяешь гипотезу, а не подгоняешь текст под исчезновение красного цвета.

## Проверка понимания

Объясни без подсказки различие JDK, JVM и IDEA. Расскажи, почему успешная компиляция не доказывает правильность вычислений. Найди корень исходников и полное имя первого упражнения. Перед практикой запусти пример и получи ровно две строки вывода.
