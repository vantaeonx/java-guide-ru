# 07. Массивы и алгоритмы над последовательностями

## Объект фиксированного размера

Массив хранит элементы одного типа. `new int[4]` создаёт объект с четырьмя int, изначально нулевыми. Ссылочный массив изначально содержит null в каждой ячейке. Длина доступна через поле `length` и не меняется. Последний допустимый индекс равен length - 1. Пустой массив существует и имеет length == 0, но не имеет ни одного допустимого индекса.

Индекс - целое int-совместимое значение. Отрицательный индекс не означает отсчёт с конца. Выход за границы вызывает ArrayIndexOutOfBoundsException во время выполнения, даже если код успешно скомпилирован. Не путай количество элементов с номером последнего.

## Копирование ссылки и данных

Присваивание `int[] b = a` копирует ссылку: a и b позволяют менять один массив. Для независимого массива нужна копия, например `Arrays.copyOf(a, a.length)`. Для массива объектов такая копия переносит ссылки на элементы, а не создаёт новые объекты элементов. Это называется поверхностной копией.

```java
import java.util.Arrays;

public class Example07 {
    public static void main(String[] args) {
        int[] heights = {3, 7, 2};
        int[] alias = heights;
        int[] copy = Arrays.copyOf(heights, heights.length);
        alias[0] = 9;
        System.out.println(Arrays.toString(heights));
        System.out.println(Arrays.toString(copy));
        int sum = 0;
        for (int value : heights) {
            sum += value;
        }
        System.out.println(sum);
    }
}
```

```output
[9, 7, 2]
[3, 7, 2]
18
```

Меняется ячейка общего объекта, а не «переменная heights целиком». Ссылка copy ведёт к другому массиву. Вывод Arrays.toString показывает элементы; прямой println массива не является удобной печатью его содержимого.

## Обход и изменение

Цикл с индексом нужен, когда важна позиция или нужно записать новое значение в ячейку. Enhanced for удобен для чтения всех элементов. Его переменная получает значение очередного элемента. Присваивание этой локальной переменной не заменяет элемент массива; для примитивов это лишь изменение копии значения. Для объектов через скопированную ссылку можно менять объект, но это тоже не заменяет ячейку.

Линейный поиск последовательно проверяет элементы. Если нужен первый подходящий индекс, остановка после находки сохраняет смысл «первый». Для отсутствия часто выбирают -1, поскольку он не является допустимым индексом. Договор о таком результате нужно явно написать.

## Фильтрация и агрегаты

У результата фильтрации заранее неизвестная длина. Без коллекций можно сначала посчитать подходящие элементы, создать точный массив, затем заполнить его вторым проходом. Это два линейных прохода. Альтернатива - временный массив максимального размера и последующая копия нужной части.

Среднее пустого массива не определено. Максимум пустого массива тоже требует отдельного договора. Не возвращай случайный ноль без объяснения: он может совпасть с законным результатом непустого входа. Условия заданий устанавливают, что делать с пустотой.

Двумерный массив Java является массивом ссылок на массивы. Строки могут иметь разную длину или быть null. Для прямоугольной таблицы используй внешний индекс строки и внутренний индекс столбца; для рваной таблицы читай длину текущей строки, а не первой.

## Ошибки и самопроверка

Если меняется «копия» и неожиданно оригинал, проверь, копировались ли данные. Если первый отрицательный максимум оказался нулём, проверь инициализацию. Если сортировка повредила исходный порядок, помни: Arrays.sort меняет переданный массив.

Перед практикой нарисуй переменные как стрелки к одному или двум прямоугольникам массивов. Покажи допустимые индексы пустого массива и массива из одного элемента. Объясни, почему два прохода могут быть проще и надёжнее одного сложного.
