Проверено 16 октября 2026 года по публичному репозиторию
https://github.com/vantaeonx/python-guide-ru, commit
`4ac9d61f87955b7e1197759210d10335c2dad23c`.
Просмотрены README, структура всех 90 заготовок, извлечённый текст PDF (104 страницы),
визуально проверены обложка, навигационные страницы, начало темы и карточка задания.

## Что работает в оригинале

- Шесть последовательных блоков по 15 заданий: пять на каждом из трёх уровней.
- Короткий путь от скачивания к запуску; зависимости для ученика минимальны.
- Файл `exNN.py` содержит условие, данные, место для обработки и вывода, проверки.
- Помимо написания программ есть прогноз, поиск ошибок и объяснение поведения.
- Объяснение и пример на другой ситуации предшествуют самостоятельной задаче.
- PDF использует ясную иерархию: крупные заголовки, цветные смысловые блоки,
  моноширинный код, отдельную карточку задания, поля для заметок, лист прогресса.
- README объясняет намеренные ошибки, пустой вывод и проблемы запуска.
- Готовые решения не включены; ожидаемые результаты служат спецификацией поведения.

## Что нужно изменить для Java

Плоские 90 файлов удобны для Python, но для Java нужны пакеты, уникальные имена классов
и явный корень исходников. Нельзя переносить Python-функции в Java механической заменой
синтаксиса: метод принадлежит классу, примитив и ссылка имеют разную семантику,
коллекции используют параметры типов, доступ регулируется модификаторами.

В оригинале основная теория распределена по небольшим карточкам упражнений. В новом
курсе перед практикой каждой темы идёт связная глава: модель выполнения, объяснение
причин, полный отдельный пример, разбор его поведения, границы применимости, ошибки
и вопросы для самопроверки. Это позволяет понимать новую идею до попытки решить задачу.

Намеренно некомпилируемый Java-код не должен ломать импорт всего проекта в IDEA.
Поэтому такие фрагменты помещены в комментарии. Ученику явно предложено перенести
фрагмент в рабочую область и исправить его. Безопасные логические ошибки могут быть
активны. Все неизменённые заготовки компилируются и завершаются; это не означает, что
они уже решают задания. Проверка стартовых файлов и проверка решений - разные вещи.

## Структура нового курса

20 глав по 9 упражнений: по три начальных, средних и сложных. Всего 180 упражнений,
плюс 6 самостоятельных мини-проектов. Пять форматов: написать, предсказать, найти
ошибку, исправить, объяснить. Номера сквозные; упражнения независимы.

1. JVM, исходник, компиляция, main и пакеты.
2. Переменные, примитивы, преобразования, ссылки.
3. Выражения, арифметика, логика, переполнение.
4. Консольный ввод, Scanner, формат данных.
5. Ветвления, логические условия, switch.
6. Циклы и инварианты.
7. Массивы и алгоритмы.
8. String, UTF-16 и обработка текста.
9. Методы, параметры, возврат, декомпозиция.
10. Классы, объекты, состояние, identity.
11. Конструкторы, private, инварианты, неизменяемость.
12. Наследование, переопределение, полиморфизм.
13. Интерфейсы, композиция, подмена зависимостей.
14. Исключения, checked/unchecked, ресурсы.
15. List и Set, изменение и порядок.
16. Map, equals/hashCode и ключи.
17. Generics, инвариантность, wildcard.
18. Path/Files, UTF-8, текстовый формат, ошибки ввода-вывода.
19. Отладка, тестирование, слои приложения.
20. enum, record, lambda, сборка приложения и следующий шаг к модам.

После глав 5, 9, 11, 16, 18 и 20 доступны мини-проекты. Основной маршрут - все задания
уровня 1 и 2, затем повторение и уровень 3. Переход определяется умением объяснить
и проверить код, а не числом дней. Лист прогресса содержит повторение через 1, 7 и 21 день.

## Границы

Курс даёт фундамент консольных приложений, а не обещание владения всей платформой.
Сеть, базы данных, многопоточность, GUI, фреймворки и конкретные API загрузчиков
Minecraft оставлены для последующего изучения. Упражнения оригинальны для Java;
сценарии Python-гайда и его код не копировались.
