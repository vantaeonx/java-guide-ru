# Словарь

| Термин | Смысл |
|---|---|
| JDK | Комплект разработки: компилятор, инструменты и среда выполнения |
| JVM | Виртуальная машина, загружающая и выполняющая байткод |
| Байткод | Представление скомпилированного кода в class-файлах |
| Пакет | Пространство имён классов, связанное с организацией исходников |
| Classpath | Корни поиска классов при компиляции или запуске |
| Тип | Договор допустимых значений и операций |
| Примитив | Непосредственное значение одного из восьми примитивных типов |
| Ссылка | Значение для обращения к объекту, либо null |
| Объект | Экземпляр класса или массив с собственной идентичностью |
| Поле | Часть состояния объекта или класса |
| Метод | Именованная операция класса с параметрами и договором результата |
| Параметр | Локальная переменная вызова в объявлении метода |
| Аргумент | Значение, переданное при вызове |
| Конструктор | Инициализация создаваемого экземпляра |
| Инвариант | Условие, сохраняемое после законных операций |
| Инкапсуляция | Контроль доступа и изменений через ясный договор |
| Наследование | Отношение типов с подстановкой подкласса вместо базового |
| Полиморфизм | Общий вызов выбирает поведение конкретного объекта |
| Перегрузка | Одно имя и разные списки параметров, выбор при компиляции |
| Переопределение | Реализация метода экземпляра в подтипе |
| Интерфейс | Договор операций, который реализует класс |
| Композиция | Объект содержит и использует другие объекты |
| Исключение | Передача управления при невозможности обычного результата |
| Checked | Исключение, требующее обработки или объявления по правилам компилятора |
| Коллекция | Структура для работы с группой элементов |
| List | Последовательность с индексами и разрешёнными дубликатами |
| Set | Набор уникальных по договору равенства элементов |
| Map | Связи уникальных ключей со значениями |
| Generic | Объявление с параметрами типов, связывающими входы и результаты |
| Wildcard | Неизвестный аргумент типа, возможно с границей extends/super |
| Boxing | Преобразование примитива в объектную обёртку |
| Неизменяемость | Отсутствие изменения наблюдаемого состояния после создания |
| Защитная копия | Копирование для сохранения контроля над внутренним состоянием |
| UTF-8 | Кодировка текста в байты, используемая для файлов курса |
| UTF-16 | Модель кодовых единиц char в строках Java |
| Регрессия | Возвращение ранее исправленной ошибки |
| Контракт | Входы, результат, побочные эффекты и отказы операции |
