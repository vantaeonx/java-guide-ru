сохранение состояния при ошибках и формат файлов. В ранней ООП-практике убраны
преждевременные зависимости от коллекций.

Намеренные ошибки не являются рабочими решениями. Некомпилируемые или опасные
фрагменты находятся в явно обозначенных комментариях. Бесконечные варианты не запускались.
Проверка десяти диагностических фрагментов не означает запуск каждого ошибочного
фрагмента: остальные проверялись чтением договора и исходника. Компиляция каркаса
не доказывает корректность ещё не написанного учеником решения.

## Воспроизведение

Для исходной редакторской копии:

```bash
python3 tools/verify.py
bash tools/build.sh
```

Для PDF после установки зависимостей в .venv:

```bash
.venv/bin/python tools/build_pdf.py
.venv/bin/python tools/check_pdf.py
pdftoppm -scale-to 1000 -png output/pdf/java-guide-ru.pdf tmp/page
```

Перед последней командой создай `tmp`. Извлечение текста не заменяет визуальный
просмотр. PDF после значимых изменений нужно заново рендерить и просматривать.
`check_pdf.py` проверяет полноту текста и геометрию, но не оценивает педагогическую
ясность или все визуальные свойства автоматически.

## Границы подтверждения

Структура Maven/исходников подготовлена для IntelliJ IDEA. Импорт и кнопки GUI самой
IDEA не автоматизировались; подтверждены javac/java, Maven и терминальные команды.
Репозиторий [vantaeonx/java-guide-ru](https://github.com/vantaeonx/java-guide-ru)
опубликован публично 17 октября 2026 года. Основная ветка — `main`.
GitHub Actions автоматически проверяет каркасы, учебные примеры и Maven-сборку
на Java 17 и 25. Актуальные результаты доступны в
[журнале CI для main](https://github.com/vantaeonx/java-guide-ru/actions/workflows/verify.yml?query=branch%3Amain).
Отдельный GitHub Release не создавался; учебник и исходники доступны в репозитории.

## Архив

`python3 tools/package.py` создаёт dist/java-guide-ru.zip и SHA256SUMS.txt.
Проверяются целостность ZIP, безопасные пути, отсутствие симлинков и ровно 206 Java-файлов.
Редактор дополнительно проверяет распаковку и сборку из отдельной папки.
