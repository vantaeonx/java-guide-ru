# Публикация и обновление репозитория

Репозиторий [vantaeonx/java-guide-ru](https://github.com/vantaeonx/java-guide-ru)
опубликован публично 17 октября 2026 года после локального просмотра и подтверждения владельца.
Основная ветка — `main`. Ниже приведён порядок проверки последующих обновлений.

## Перед загрузкой

- Выполнить `python3 tools/verify.py` в исходной редакторской копии.
- Убедиться, что PDF соответствует последним условиям и просмотрен после вёрстки.
- Проверить состав Git: нет учебных решений, build/target, личных путей и секретов.
- Не включать локальную учебную копию, в которой уже решались задачи.
- Подготовить архив через `python3 tools/package.py`, проверить распаковку.

## Состав выпуска

Теория, заготовки, каталог условий, примеры, PDF, документация, ресурсы и инструменты.
Архив релиза берётся из dist/java-guide-ru.zip; SHA256SUMS.txt находится рядом.
В Git не включаются временный JDK, зависимости в .venv и результаты локальных запусков.

## Проверка после публикации обновления

Проверить владельца, имя и публичную видимость репозитория, ветку по умолчанию,
полное совпадение дерева Git с опубликованным коммитом. Дождаться CI на Java 17 и 25.
Затем проверить скачанный архив выпуска: PDF и 206 Java-файлов (180 упражнений,
6 проектов, 20 примеров). Только после этого считать удалённый выпуск проверенным.

Готовые решения в публичную ветку не добавлять. Исправления учебных условий должны
изменять каталог, затем проходить генерацию, компиляцию, обновление PDF и проверку
архива. Номера упражнений в опубликованном выпуске сохранять стабильными.
